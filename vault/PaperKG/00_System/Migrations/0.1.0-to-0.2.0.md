# PaperKG 0.1.0 → 0.2.0

## 목적

형식상 유효하지만 연구 비교에는 불완전했던 노트를 의미 수준에서 검증할 수 있도록 강화한다.

## 변경 사항

- Claim, Contribution, Method, Protocol, ResultSet, Baseline 및 회의 파생 타입에 전용 스키마를 적용한다.
- `source_document`에 원문·번역·교차본 역할, 언어, 파생 출처를 기록한다.
- `benchmark_use`에 configuration fingerprint와 완성도를 추가한다.
- 비교 가능성을 단일 사용의 속성만으로 판단하지 않고 `comparison_assessment`에서 두 사용 사이의 관계로 판정한다.
- `paperkg-resultset` block을 행 단위 정량 결과의 정본 표현으로 사용한다.
- 단순 소속은 파생 `part_of_version` edge로 만들고, 인과·학술 해석만 evidence-bearing Relation note로 유지한다.
- 한국어·영어 preferred label과 alias를 검색 어휘에 포함한다.

## 실행

```powershell
pnpm exec tsx scripts/migrate-paperkg-0.1-to-0.2.ts --vault=vault/PaperKG
pnpm exec tsx scripts/migrate-paperkg-0.1-to-0.2.ts --vault=vault/PaperKG --apply
pnpm paperkg validate vault/PaperKG
pnpm paperkg audit vault/PaperKG
```

첫 명령은 dry-run이고 `--apply`만 atomic file replacement를 수행한다. 재실행해도 변경이 없는 idempotent migration이다.
