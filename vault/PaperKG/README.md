# PaperKG 지식망

이 보관함은 논문 지식의 정본입니다. 평소에는 폴더를 직접 뒤질 필요 없이 왼쪽 리본의 **PaperKG 열기**를 누르고 **한눈에 보기** 화면부터 보면 됩니다.

## 가장 쉬운 사용 순서

1. **한눈에 보기**에서 논문 수, 평가 설정, 문제 정의와 공통 한계를 확인합니다.
2. 논문 하나를 찾을 때는 **논문 탐색**에서 제목이나 별칭을 검색합니다.
3. 결과를 비교할 때는 **벤치마크 비교**에서 목적·분할·프로토콜·지표와 비교 가능 상태를 확인합니다.
4. 연구 흐름은 **문제 변화**, 반복되는 약점은 **한계 계보**에서 봅니다.
5. 원문 근거가 필요할 때만 오른쪽 위의 **근거 보기**를 엽니다.

## 계속 보고 있지 않아도 됩니다

- Obsidian이 열려 있을 때 Markdown이나 제안 파일이 바뀌면 PaperKG 화면이 자동으로 다시 읽습니다.
- Obsidian을 닫아도 정본 Markdown은 그대로 보존되며, 다음에 열 때 최신 상태를 다시 읽습니다.
- 새 추출 결과와 회의 내용은 내부 후보 영역을 거치며, 검증된 정본만 화면에 표시됩니다.
- **데이터 품질**이 오류 0건이면 당장 처리할 무결성 문제가 없습니다.

승인된 지식은 `01_Sources`부터 `08_Ideas`까지의 Markdown/YAML에 있습니다. `09_Views`, `10_Inbox`, PDF, SQLite와 검색 인덱스는 정본 지식이 아닙니다.
