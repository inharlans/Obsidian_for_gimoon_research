# PaperKG 시작 화면

왼쪽 리본의 **PaperKG 열기**를 눌러 연구 지식망 화면을 엽니다. 처음에는 **한눈에 보기**가 표시됩니다.

## 화면을 보는 법

- **논문 탐색**: 논문 한 편의 문제의식, 방법, 벤치마크와 관계를 찾습니다.
- **벤치마크 비교**: 같은 벤치마크 이름이 아니라 실제 평가 조건과 비교 가능 상태를 봅니다.
- **문제 변화**: 카드는 최초 공개일 순서입니다. 카드 사이 선은 인과관계를 뜻하지 않습니다.
- **한계 계보**: 여러 논문에서 반복되는 한계와 발생 사례를 봅니다.
- **버전 비교**: 같은 연구의 arXiv·학회판 차이를 확인합니다.
- **데이터 품질**: 오류·중복 ID·근거 누락 여부를 확인합니다.

## 지식망의 안전 규칙

- 알려지지 않은 프로토콜은 추측하지 않고 미확인으로 둡니다.
- 시간상 뒤에 공개됐다는 사실을 인과관계로 해석하지 않습니다.
- 저자가 명시한 내용과 해석자가 정리한 내용을 분리합니다.
- 벤치마크 이름이 같다는 이유만으로 결과가 직접 비교 가능하다고 판단하지 않습니다.
