# ALMA main empirical claim

## 정의

ALMA가 학습한 memory design은 네 benchmark에서 human-designed memory보다 높은 success, transfer, data scaling, distribution-shift adaptation과 낮은 평균 memory cost를 보인다.

## Claim

ALMA가 학습한 memory design은 네 benchmark에서 human-designed memory보다 높은 success, transfer, data scaling, distribution-shift adaptation과 낮은 평균 memory cost를 보인다.

## Scope

이 주장은 [[rs_alma]]의 paper-specific protocol과 비교군 안에서만 해석한다. 같은 benchmark 이름만으로 다른 논문의 수치와 직접 비교하지 않는다.
